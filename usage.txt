## Install docker


## Install nvidia docker container tool kitç
## https://docs.nvidia.com/datacenter/cloud-native/container-toolkit/latest/install-guide.html

## clone yolox

## Build yolox image
docker built -t yolox:latest .

## Run image
docker run --gpus all -v <path_to_dataset>:/home/data -v <path_to_code>/YOLOX/:/home/code -ti yolox:latest

## Note that Yolo is not copied, but it is mounted as a volume, to easly modificate the code if necessary. 
## This can be modified after testing YoloX works
## First time runing this image, YoloX must be installed
cd home/code/
pip install -v -e .
